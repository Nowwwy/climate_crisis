# 보이지 않는 비 · 기후위기 취약 상권 분석

2026 빅콘테스트 AI·데이터분석 분야 **너의 상권은** 팀의 프로젝트입니다. 2025년 7~12월 서울 강남구와 춘천시의 선정 업종을 대상으로 영업시간 강수와 카드 매출의 관계를 분석했습니다. 강수 사건별 매출 부족액과 회복 기간을 추정하고, 기후 회복탄력성 지수로 지원 우선 검토 대상을 살펴봅니다.

## 프로젝트 파일

- [전체 분석 노트북](%EA%B8%B0%ED%9B%84%EC%83%81%EA%B6%8C_%EC%A0%84%EC%B2%B4%EB%B6%84%EC%84%9D_Colab.ipynb) · 데이터 전처리, 기상 반응과 피해·회복 분석, 지수 산출 및 검증
- [결과보고서 PDF](AI%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B6%84%EC%84%9D%20%EB%B6%84%EC%95%BC_%EB%84%88%EC%9D%98%20%EC%83%81%EA%B6%8C%EC%9D%80_%EA%B2%B0%EA%B3%BC%EB%B3%B4%EA%B3%A0%EC%84%9C.pdf) · 연구 배경, 분석 결과, 상권별 지원 방안과 연구 한계

## 분석 흐름

1. 신한카드 매출과 기상청 관측을 결합하고, 업종·지역별 강수 및 기온과 매출의 관계를 살펴봅니다.
2. 평상시 매출 기준선을 추정해 강수 사건별 매출 부족액과 회복 기간을 계산합니다.
3. 기후 회복탄력성 지수를 산출하고, 과거 사건으로 이후 사건을 평가하는 순차 검증을 수행합니다.
4. 공식 상권 경계와 SKT 유동인구를 활용해 상권별 노출과 지원 우선순위를 살펴봅니다.

## Colab에서 실행

1. 노트북을 Google Colab에서 엽니다.
2. 별도로 확보한 신한카드, SKT 유동인구, 기상청 원본 ZIP 3종을 Google Drive의 `MyDrive/side_pjt/`에 둡니다. 다른 위치를 사용하려면 설정 셀의 `ZIP_DIR`을 지정합니다.
3. 기상 입력에 `chuncheon_asos_daily.csv`, `chuncheon_asos_hourly.csv`, `gangnam_aws_hourly.csv`가 있는지 확인합니다.
4. 셀을 위에서부터 실행합니다. 공식 상권과 연계한 분석에는 소상공인시장진흥공단 상가(상권)정보 API 키가 필요합니다. `SERVICE_KEY`를 비워 두면 해당 단계는 건너뜁니다.
5. 기본 작업 경로 `/content/bigcon_final/` 아래의 `out_round2/`, `fig_round2/`, `report_figs/`에서 결과를 확인합니다.

이 저장소에는 원본 데이터와 노트북의 실자료 실행 출력이 포함되어 있지 않습니다. 분석 결과는 선정 업종과 관측 기간에 대한 추정치이며, 기후변화로 인한 인과적 피해나 개별 사업체의 지원 자격을 확정하는 데 사용할 수 없습니다.
